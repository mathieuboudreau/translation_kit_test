# Getting started

Before you begin, install **Git** and create a free [GitHub account](https://github.com/signup).

```bash
git clone https://github.com/mathieuboudreau/translation_kit_test.git
cd translation_kit_test
```

:::{note}
Commit your work often, and write short, clear commit messages.
:::
